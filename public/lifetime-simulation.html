소리와 사용량으로 살펴보는 수명

STFT로 소리를 살펴보고, Weibull-AFT로 앞으로의 사용 횟수를 계산해요.

예시 자료: SMC CD85N25-25-B · 1번 실린더에서 녹음한 정상 소리

가상 시나리오 · 실제 수명 예측이 아닙니다.
직접 녹음한 소리를 사용했어요. 사용 횟수와 고장 기록은 가정한 값이에요. 아래 숫자는 조건을 바꿔 보는 예시이며, 현재 보고 있는 장치의 실제 남은 수명은 아닙니다.

얼마나 사용했다고 가정할까요?

모의 학습 범위: 0~100,000회. 센서 패킷 수를 왕복 횟수로 세지 않습니다.

처음부터 예상한 전체 사용 횟수계산 준비 중가정한 누적 사용량 + 앞으로 더 사용할 횟수 · 평균
앞으로 더 사용할 횟수 · 평균계산 준비 중가정한 현재 시점부터의 분포 평균
절반이 고장에 도달하는 횟수계산 준비 중가상 개체 절반이 고장에 도달하는 횟수

더 사용하면 어떻게 달라질까요?

가로는 앞으로 더 사용하는 횟수, 세로는 가상 실린더가 고장 없이 남아 있는 비율이에요.

어떤 자료를 사용했나요?

직접 측정: 1번 실린더의 정상 소리 537개 구간을 분석했어요.
가정한 값: 사용량과 고장 기록, 소리가 수명에 미치는 관계를 설정했어요.

계산 방법과 가정 자세히 보기
구분내용
실제 측정정상 1세션 537패킷, 센서별 저장 음향 34.368초. INMP441 STFT 창 RMS를 패킷별 평균한 특징.
가상 자료실제 특징을 재사용한 가상 개체 80개. 독립적인 실제 실린더 80개가 아닙니다.
가정한 관계표준화 소리 특징이 1 증가할 때 잔여수명 척도 ×exp(−0.25), 누적 사용 10만 회 증가 시 ×exp(−0.35). 실측으로 확인한 관계가 아닙니다.
기준값다른 실린더의 논문 고장 기록 5개를 재계산한 평균 약 135,360회를 모의 생성 기준으로 사용. 해당 논문에는 우리 STFT 특징이 없습니다.
모델가상 고장·관찰 종료 자료로 최대우도 Weibull-AFT 적합. 단위는 왕복 횟수, 예측 기준점은 가정한 현재 시점.
