논문 기준과 시현 소리 비교

간헐 동작을 전제로 같은 Pico의 새 DB 소리를 비교합니다. 정상 기준에서 학습한 실험용 활동성 기준으로 낮은 소리 구간을 제외합니다. 같은 시현 구간에서 최대 3분 동안 독립 음향 후보를 모아 최근 5개부터 비교하며 실제 동작 5회라는 뜻은 아닙니다. 실제 상태를 바꾸면 분석기를 다시 시작해 이전 상태 후보를 비우세요.

1. 논문 수명 기준

논문의 NBR 고장 5개가 기본값입니다. 저자 보고 평균 167,500회와 재적합 결과는 다릅니다. 수정한 목록은 사용자 가설값입니다.

2. 소리 비교와 사용량 확인

0이면 소리 영향을 적용하지 않습니다. 0.25는 논문에서 검증된 계수가 아닙니다.

누적 횟수는 사용 시작부터 실제 계측한 값만 입력합니다. 패킷 수·녹음 길이·수신 간격을 왕복 횟수로 바꾸지 않습니다. 영상 환산은 동일 속도로 확인된 운전 구간에만 적용하며 이전 사용량을 만들어 넣지 않습니다. 미상이면 잔여수명을 계산하지 않습니다.

정상 BASELINE/UNASSIGNED만 기준 생성에 사용합니다. 구간의 실제 상태·실물·조건을 구분합니다. 정상·비정상이 섞인 운영 자료 전체를 현재 상태나 수명의 대표값으로 해석하지 않습니다.

계산식과 출처

λ(D) = λ₀ × exp(−γD)
S(N|D) = exp(−(N/λ(D))ᵏ)
P(잔여 > r | 현재 a까지 생존) = S(a+r|D) / S(a|D)

정상 평균·변동으로 표준화한 STFT 거리의 정상 95분위 초과량을 log(1+초과량)으로 표현한 값이 D입니다. 실험용 소리 편차이며 수명 영향 γ는 가설입니다. 평균은 조건부 생존곡선을 적분합니다.
