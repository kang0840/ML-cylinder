실측 소리로 비교하는 모의 수명

DB 분석 자료 확인 중

가설 기반 시뮬레이션 · 실제 교체 시기 예측 아님

소리와 STFT 특징은 실측 자료입니다. 논문의 고장 횟수는 다른 시험에서 나온 기준이며, 소리의 수명 영향은 가정이며, 누적 사용량은 실측값이 있을 때만 입력합니다. 정상·누설 라벨을 고장 시점으로 변환하지 않습니다.

자료는 Pi 분석 실행 시 갱신됩니다. 웹 조절값은 브라우저 계산에만 사용하며 DB·PLC에 쓰지 않습니다.

수집 구간과 정지시간

시간 자료 확인 중

패킷 사이의 음향을 무음으로 채우거나 이어 붙이지 않습니다. 패킷별 STFT이며 패킷 수와 왕복 횟수는 다릅니다.

1. 논문 수명 기준

논문의 NBR 고장 5개가 기본값입니다. 저자 보고 평균 167,500회와 재적합 결과는 다릅니다. 수정한 목록은 사용자 가설값입니다.

2. 소리 비교와 실측 사용량

0이면 소리 영향을 적용하지 않습니다. 0.25는 논문에서 검증된 계수가 아닙니다.누적 횟수는 사용 시작부터 실제 계측한 값만 입력합니다. 데이터 양·녹음 길이·수신 간격을 왕복 횟수로 바꾸지 않습니다. 미상이면 잔여수명을 계산하지 않습니다.

가정한 조건에서의 결과

누적 사용량계산 대기
앞으로 더 사용할 횟수 · 평균계산 대기
앞으로 더 사용할 횟수 · 중앙값계산 대기
사용량 + 평균 잔여 횟수계산 대기

현재 사용량까지 고장 없이 도달했다는 조건을 반영합니다. 실제 예측 정확도·실측 잔여수명 비율을 뜻하지 않습니다.

패킷별 STFT의 평균 주파수 성분

정상 기준씰 누설
같은 설정을 적용한 패킷별 결과입니다. log(1+진폭)이며 절대 음압·물리 누설량·자동 잡음 제거 결과가 아닙니다.

사용한 DB 세션

실험실제 라벨자료 용도패킷관측 구간중앙 편차 D
정상 BASELINE/UNASSIGNED만 기준 생성에 사용합니다. 누설 VALIDATION은 비교 대상으로 사용하며 고장 학습 자료로 바꾸지 않습니다.

계산식과 출처

λ(D) = λ₀ × exp(−γD)
S(N|D) = exp(−(N/λ(D))ᵏ)
P(잔여 > r | 현재 a까지 생존) = S(a+r|D) / S(a|D)

정상 평균·변동으로 표준화한 STFT 거리의 정상 95분위 초과량을 log(1+초과량)으로 표현한 값이 D입니다. 실험용 소리 편차이며 수명 영향 γ는 가설입니다. 평균은 조건부 생존곡선을 적분합니다.
