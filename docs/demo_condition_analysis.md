# 간헐 시현 소리와 기존 측정 기준의 모의 수명 비교

## 실행

Pi의 기존 **08. 모의 수명 분석** 아이콘 또는 아래 기존 실행기를 사용한다.

```sh
bash /opt/smart-cylinder-pi5/deploy/run_lifetime_simulation.sh
```

실행 중에는 독립 분석기가 Pico별 SQLite를 3초 간격으로 읽는다. 기존 센서 수집기는 별도로 실행되어 OPERATION 원본을 저장해야 한다. MQTT 수신기·YOLO·DB STFT worker를 시작/종료하지 않으며 새 MQTT 연결을 만들지 않는다. Ctrl+C로 이 분석만 종료한다. 중복 실행은 별도 lock으로 거절한다. 기존 라벨 실험 분석은 같은 실행기의 `--historical --labeled-experiments` 옵션으로 보존한다.

Pi 화면: `http://192.168.1.1:8000/lifetime-condition.html`. Render는 별도 배포 시점의 스냅샷이며 Pi 실행만으로 공개 자료가 자동 전송되지 않는다. 화면에 공개 스냅샷/시현 신규 자료/과거 재현을 구분한다.

## 분석 대상과 간헐 동작

- 시작 시 각 Pico의 원본 ID 상한을 기록하고 그 뒤에 저장된 OPERATION만 비교한다. 과거 혼합 운영 전체로 현재 상태를 대표하지 않는다.
- 최신 한 세션의 최대 50패킷 안에서 음향 후보 5개부터 결과를 낸다. 이는 왕복 5회나 검증된 최소 표본 수가 아니다. 세션·기준 채널·실물·조건은 구분하고 다른 Pico로 기준을 채우지 않는다. 알려진 실물/조건 불일치는 차단하며, OPERATION에 조건이 없으면 미확인 비교임을 표시한다.
- 정상 기준의 두 RMS 로그 에너지 군집이 충분히 떨어졌을 때만 실험용 활동성 기준을 만든다. 낮은 활동성 후보를 정상·누설·시현에 같은 기준으로 제외한다. 군집이 구분되지 않으면 기준 부족으로 중단한다.
- 이 기준은 기계 정지·왕복을 검출한 정답이 아니다. 누설·배기·다른 기계가 통과하거나 실제 동작이 제외될 수 있다. 별도 정지 배경과 수동 확인을 이용한 성능 검증은 남아 있다.
- 독립 음향 후보는 같은 시현 시작 경계·같은 세션 안에서 최대 3분까지 보관하고 최근 5개의 STFT 특징을 비교한다. 정지 중 패킷은 후보 수를 늘리지 않으며 계속 운전할 필요가 없다. 음향 파형이나 운전시간을 합치는 것이 아니다. 실제 상태를 바꾼 경우 Ctrl+C 후 다시 시작하여 이전 상태 후보를 비운다. 후보가 10초 넘게 없거나 새 패킷이 30초 넘게 없으면 현재 수명 숫자를 표시하지 않는다. 음향을 연결하거나 공백을 무음으로 채우지 않는다.

## 기존 측정 기준

수동 NORMAL TRAINING 중 BASELINE/UNASSIGNED만 정상 기준에 사용한다. 같은 실물·조건의 수동 SEAL_LEAK는 별도 비교 스펙트럼으로 사용하되 TEST는 참조에 사용하지 않는다. VALIDATION 누설을 비교 기준으로 사용했음을 기록하며 그 자료로 독립 성능을 검증했다고 보고하지 않는다. 정상 평균·변동·정상 95분위로 표준화한 STFT 거리와 누설 평균까지의 상대 거리를 각각 표시한다. 가까운 기준은 정상/비정상 정답이나 고장 확률이 아니다.

기준 모델은 기존 data 폴더의 `lifetime-demo-reference-picoNN.json`에 저장한다. 캐시는 원본 DB·세션·원본 수/상한·설정에 연결하며 시작 시 재사용한다. 시현 중 기준 원본 삭제/라벨·조건 변경을 감지하면 결과를 차단한다. 원본 DB/라벨/스키마에는 쓰지 않는다.

## 논문 기준과 결과

기본 평균 수명 기준은 논문 저자 보고 **167,500왕복**이다. 사용자가 화면에서 정수로 수정할 수 있으며 브라우저 계산에만 반영한다. 형상 k는 기존 논문 고장 5건을 재적합한 값이며, 척도는 선택한 평균에 맞춰 `lambda0=mean0/Gamma(1+1/k)`로 산출한다. 저자 평균과 원시 5건의 별도 재적합 평균은 다름을 유지한다.

`lambda(D)=lambda0*exp(-gamma*D)`, `E[T|sound]=mean0*exp(-gamma*D)`를 사용한다. gamma 기본 0.25는 실측 고장 관계로 학습한 계수가 아닌 가정이다. 평균·중앙 수명과 총 수명 생존곡선을 표시하며, 전체 누적 사용량이 미상이어도 이 무조건부 상태별 평균 수명은 계산할 수 있다. 모르는 과거 사용량을 0으로 넣거나 age=0으로 대체해 잔여수명이라고 표시하지 않는다. actual_age_cycles/remaining_cycles는 NULL이다.

전진+후진=왕복 1회. 횟수 표시는 정수 반올림이다. DB 패킷 수는 Pico별 수집량이며 기계 사용 횟수로 빼지 않는다. 확인된 Pico05 과거 6세션 영상 환산만 기존 사용량 패널에서 약389회로 별도 유지하고 현재 시현에 소급 적용하지 않는다.

## 검증과 한계

실제 PCM/SQLite 검사는 정상·누설 주파수 차이/정지 음향 후보/새 세션/시현 시작 경계/오래된 데이터/누락 시간/기준 삭제 차단과 원본 보존을 검증한다. Python/JS 수치 일치를 검증한다. 과거 DB 재현은 명시 `--replay`를 사용하며 현재 실센서 시현 성공과 구분한다. 실제 간헐 동작의 분리 정확도·고장 관계·RUL 성능은 검증하지 않았다.
