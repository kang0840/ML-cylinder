# 실측 STFT 기반 모의 수명 사용법

Pi 바탕화면 `08. 모의 수명 분석`을 실행한다. 기존 DB 원본을 읽어 계산하며 수집기·YOLO를 시작하거나 중단하지 않는다. 완료 뒤 `http://192.168.1.1:8000/lifetime-condition.html`을 새로고침한다. 터미널에서는 `/bin/bash /opt/smart-cylinder-pi5/deploy/run_lifetime_simulation.sh`로 실행한다.

공개 화면은 `https://ml-cylinder.onrender.com/lifetime-condition.html`이다. 공개 화면은 배포 시점의 분석 스냅샷이다. Pi에서 재분석하면 Pi 웹 자료만 갱신되며 Render 자료는 다시 배포해야 갱신된다. 화면의 자료 생성 시각을 확인한다.

논문 고장 횟수 목록을 수정하여 와이블을 재적합하거나, 직접 설정 모드에서 형상과 척도를 수정한다. 누적 사용량은 실제로 계측한 누적 왕복 횟수만 입력한다. 기본 횟수나 시간/가정주기 환산을 제공하지 않으며 미상이면 잔여수명을 계산하지 않는다. 소리 영향 계수와 외부 수명 기준은 가설이다. 결과와 출처는 JSON으로 내려받을 수 있다. 브라우저 조절은 DB·장비 설정을 바꾸지 않는다.

최초 분석은 Pico05/CYL-005 정상 8세션 2572패킷과 누설 6세션 1772패킷이다. 동일 실물·조건만 비교하며 정상 BASELINE/UNASSIGNED를 기준으로 사용한다. 패킷별 STFT를 계산하고 수신 공백을 음향으로 이어 붙이지 않는다. 확인된 누설 6세션 사이 정지시간만 제외하며 운전 관측 구간은 1011.437089초다. 패킷 수나 수신 간격은 왕복 횟수가 아니다.

수명은 논문 고장 자료의 완전고장 Weibull MLE에 가설 척도 보정 λ(D)=λ₀exp(-γD)를 적용하고 조건부 생존 S(a+r)/S(a)로 평균·중앙 잔여 횟수를 구한다. γ는 실측 고장으로 학습한 계수가 아니다. 최초 자료의 정상·누설 대표 D는 모두 0으로, 이 특징에서는 정상 변동 범위 밖의 대표 차이를 확보하지 못했다. 따라서 같은 사용량에서 대표 수명 차이가 생기지 않는다. 실제 판별 성능이나 교체 시기 검증으로 해석하지 않는다.

원본·라벨·중앙 DB 구조·MQTT 계약은 변경하지 않는다. 분석 JSON은 기존 Pi data 폴더, 웹 요약은 기존 public 폴더에 원자적으로 교체한다. 인증값과 PCM은 공개 요약에 포함하지 않는다.

## 2026-11-04 실측 사용량 및 운영 데이터 변경
기본 가정 사용량 50,000회와 시간/가정주기 환산을 화면에서 제거했다. 실측 누적 왕복 횟수 미상은 잔여수명 계산을 차단하며 STFT는 표시한다. 논문 고장횟수는 외부 기준이고 소리 영향은 여전히 가설이다.
분석기의 --operation-since ISO8601 옵션은 해당 시각 이후 라벨 없는 OPERATION 원본을 정상 기준과 비교한다. 같은 채널의 실물·조건 일치는 미확인으로 표시한다. 수집기는 분석과 독립이다. 이번 3분 수집은 원본 0건으로 새 분석 결과를 생성하지 않았다. 기존 스냅샷은 이전 자료다.
