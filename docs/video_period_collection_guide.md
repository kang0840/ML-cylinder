# 영상 주기를 적용한 모델: 필요한 데이터와 수집 방법

## 이번에 적용한 값과 범위

- 영상: 20261104_150725.mp4, 같은 방향 이동 9회로 8개 왕복 간격 측정.
- 평균 왕복 주기: 2.6016069444초, 약 23.06회/분. 선형 이동속도 mm/s와는 다르다.
- 사용자 확인: 해당 실험과 영상의 운전 속도가 같음.
- 적용: Pico05/CYL-005의 정지 확인된 기존 누설 6세션에만 적용.
- 세션별 첫~마지막 Pi 수신시각 합 1011.437089초를 나누면 약 388.77회.
- 이는 관측 구간의 환산값이다. 실험 이전 사용량은 NULL이며 총 누적량을 389회로 만들지 않는다.
- 웹의 영상 모드에서 이전 실측 누적횟수가 있어야 총 사용량을 구성한다. 미상은 빈칸으로 두고 0을 넣지 않는다. 수명 값은 계속 논문 기준·소리 영향 가설에 따른 모의값이다.

다른 채널·실물·새 실험에 같은 주기를 자동 적용하지 않는다. 압력·속도 설정·부하가 달라지면 주기를 다시 확인하고 적용 구간을 별도로 기록한다. 주기 관측 범위로 구한 횟수 범위는 통계적 신뢰구간이 아니다.

## 소리 상태 판별을 위해 지금 모을 자료

| 자료 | 수집 방법 | 기록 |
|---|---|---|
| 채널별 정상 | 01→03→05를 한 대씩 실제 정상 상태에서 수집 | NORMAL, 실물번호, 세션, 기준/검증/시험 용도 |
| 채널별 실제 누설 | 누설이 실제 확인된 상태를 같은 장착·조건에서 수집 | SEAL_LEAK, 확인 방법·시점, 실물번호 |
| 배경 소음 | 전부 정지한 구간을 일반 수집으로 기록 | 시작/종료시각과 배경 수집임을 별도 메모, 정상 라벨 자동 부여 금지 |
| 동시 동작 | 개별 수집과 별도 실험으로 3대 동시 운전 | 운전 채널·각 실제 상태·시각, 출처가 불명확하면 정상/누설로 임의 확정 금지 |
| 조건·사용량 | 실제 운전 시작·정지와 계측 카운터를 기록 | 압력, 부하, 장착, 마이크 거리, 계측/영상 환산 구분, 이전 사용량 미상 여부 |

권장 시작 절차:

1. `01. 수집 모드 선택`에서 E로 대상 Pico만 설정한다. 시험 대상이 아닌 장치는 일반 수집으로 구분한다.
2. 실제 정상은 1, 실제 누설은 2를 선택하고 새 실험 이름을 지정한다. 원인 불명 소음이나 씰 손상 사실만으로 실제 누설을 확정하지 않는다.
3. 고정 조건이 그대로라면 추가 조건 Enter로 기존 기본값을 사용한다. 현재 알려진 01/03/05 조건은 공급압력 0.2MPa, 실린더 표면 기준 두 마이크 거리 5mm다. 실제로 달라졌으면 E로 수정한다. 미측정 속도·부하는 빈 값으로 남긴다.
4. 정상 기준 수집은 BASELINE, 임계값 확인은 VALIDATION, 마지막 독립 평가는 TEST로 구분한다. 누설은 BASELINE으로 저장하지 않는다.
5. YES 확인 후 구독 준비 표시를 보고 Pico를 새로 부팅한다. 저장 성공을 확인하고, 시작·정지·주기 변경 시각을 남긴다. 재부팅에 따른 새 세션 번호와 실제 운전 정지 여부는 구분한다.
6. 먼저 짧은 정상·누설 시범 수집에서 실제 센서 반응과 파형·STFT 차이를 확인한다. 기존 대표 편차가 둘 다 0이므로 많은 양부터 모으기보다 목표 소리가 실제로 담기는지 먼저 점검한다. 이후 하루 한 긴 녹음만 모으기보다 여러 번 독립 수집한다. 실무 시작안으로 상태별 3~5개 독립 세션을 먼저 검토할 수 있으나 이는 보장된 최소량이 아니다. 실제 운전 반복과 소리 차이·녹음 품질·세션 간 변동을 보고 추가한다.
7. 같은 세션의 이웃 패킷을 학습·시험에 섞지 않는다. 세션 단위로 분리하고, 다른 실물에 대한 성능을 주장하려면 실물도 분리한 평가가 필요하다. 정상과 누설을 서로 다른 Pico로만 수집하지 않는다.

각 단계의 NORMAL/SEAL_LEAK는 실제 상태 정답이다. 모델 예측과 구분하며 일반 OPERATION을 정상으로 자동 변환하지 않는다. 세션별 원본 PCM은 보존하고 패킷·세션 사이 음향을 연결하지 않는다.

## 실제 수명 모델을 위해 별도로 필요한 자료

| 항목 | 남길 내용 |
|---|---|
| 실물의 사용 시작점 | 새 실물의 시작, 또는 확인 가능한 기존 누적계수. 미상은 0으로 대체하지 않음 |
| 누적 사용량 | 가능하면 PLC/실제 계수기의 왕복 카운터. 영상 주기 환산은 출처·적용 구간·정지 제외 여부를 별도 표시 |
| 고장 기준 | 실험 전에 정한 실제 고장 기준과 확인 방법. 누설 라벨을 자동으로 고장 이벤트로 바꾸지 않음 |
| 고장/미고장 이력 | 고장 시 누적량·시각, 끝까지 미고장이면 관측 종료 누적량·시각(우측 검열). 뒤늦게 발견한 고장은 확인 가능한 발생 구간 기록 |
| 여러 개체의 이력 | 서로 다른 실물번호로 반복. 한 실물의 수천 패킷을 수천 개체의 고장 기록으로 사용하지 않음 |

과거 사용량을 모르는 현재 실물도 소리 기준/상태 검증에는 활용할 수 있다. 절대 누적량을 모르는 사실은 그대로 두며, 실제 수명 학습에는 알려진 시작점 또는 적절한 별도 관측 설계가 필요하다. 데이터가 충분해지면 현재 논문 기준과 소리 영향 가설을 자체 운전·고장 자료로 추정하고 독립 평가한다.
